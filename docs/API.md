# API Reference

Base URL (production): `https://link-analysis.lunarnodes.co.in`
Base URL (local): `http://localhost:4000`

Interactive documentation (try requests in the browser): **`/docs`** (Swagger UI) · **`/redoc`** · OpenAPI schema: **`/openapi.json`**

---

## Endpoints

| Method | Path | Purpose |
|---|---|---|
| `POST` | `/link-analysis` | Analyze a website and return the 5-section report |
| `GET` | `/health` | Service status and active model |
| `GET` | `/` | Web interface |

## `POST /link-analysis`

### Request

```http
POST /link-analysis
Content-Type: application/json
```

```json
{ "url": "https://example.com" }
```

| Field | Type | Rules |
|---|---|---|
| `url` | string | Required, 1–2048 characters. `https://` is added when missing. Only `http`/`https` on ports 80/443. Public hosts only. |

Optional header: `X-Request-ID` (max 64 characters) is echoed back for tracing. One is generated when absent.

### Examples

**cURL**
```bash
curl -X POST https://link-analysis.lunarnodes.co.in/link-analysis \
  -H "Content-Type: application/json" \
  -d '{"url": "hubspot.com"}'
```

**Python**
```python
import httpx

resp = httpx.post(
    "https://link-analysis.lunarnodes.co.in/link-analysis",
    json={"url": "hubspot.com"},
    timeout=120,
)
data = resp.json()
if data["success"]:
    for q in data["analysis"]["target_search_queries"]:
        print(q["query"], q["platforms"])
else:
    print(data["error"]["code"], data["error"]["message"])
```

**JavaScript**
```js
const res = await fetch("https://link-analysis.lunarnodes.co.in/link-analysis", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ url: "hubspot.com" }),
});
const data = await res.json();
```

### Successful response: `200 OK`

A complete real response is in [`examples/stripe.com.json`](examples/stripe.com.json).

```text
{
  success: true
  website: string                     final URL after redirects
  brand: { name, category, summary }
  analysis: {
    competitor_analysis: {
      brand_overview, business_category, products_and_services[],
      your_target_market, your_key_strength,
      competitors[]: { name, website|null, main_service, target_market,
                       strengths[], weaknesses[],
                       source: "ai_suggested" | "web_grounded", source_urls[] },
      strengths[],                    your competitive advantages
      opportunities[],                positioning improvements
      disclaimer
    }
    target_search_queries[5]: { query, platforms[]: "Google"|"Facebook"|"Instagram"|"LinkedIn"|"X",
                                intent, business_relevance, target_audience }
    search_queries_note: { search_volume: "not_provided", reason }
    seo_improvements: {
      primary_keyword, secondary_keywords[], long_tail_keywords[], business_keywords[],
      current_title, recommended_title, title_structure,
      current_meta_description, meta_description,
      technical_audit[]: { check, status: "pass"|"warn"|"fail", finding, recommendation|null },
      supporting_content[]: { type: "service_page"|"industry_page"|"faq"|"blog_topic"|
                                    "location_page"|"article"|"case_study", title, purpose }
    }
    top_services[1..5]: { name, description, target_industry, target_customer, main_benefit,
                          source: "website" | "inferred" }
    target_audience: {
      primary_audience[], secondary_audience[], industries[], business_types[],
      customer_profiles[], geographic_focus|null, customer_needs[], challenges[], interests[],
      recommended_segments[]: { segment, business_type, requirement }
    }
  }
  meta: {
    model, cached, latency_ms, llm_latency_ms,
    tokens: { input, output, thinking },
    estimated_cost_usd,               0 when served from cache
    pages_analyzed[], warnings[], analyzed_at (ISO-8601 UTC)
  }
}
```

#### Field notes

- `brand`, `competitor_analysis`, `top_services` and `target_audience` are grounded in the website's own text. The prompt forbids inventing facts about the business.
- `competitors[].source`: `ai_suggested` comes from model knowledge; `web_grounded` comes from live Google Search with citations (requires `ENABLE_SEARCH_GROUNDING=true`). The analyzed brand and duplicates are removed automatically.
- `technical_audit` is **measured from the HTML** (11 checks), not generated by the AI.
- `search_queries_note.search_volume` is always `"not_provided"`. No search-volume data source is connected, so none is invented.
- `meta.warnings` explains reduced-quality situations, for example a JavaScript-rendered homepage or fewer than 3 reliable competitors.

### Error responses

All errors use one envelope:

```json
{
  "success": false,
  "error": {
    "code": "site_access_denied",
    "message": "This website refused automated access (bot protection or login wall).",
    "request_id": "f8e53bc26018ff3d",
    "details": { "status": 403 }
  }
}
```

| HTTP | `code` | Meaning | Client action |
|---|---|---|---|
| 422 | `invalid_request` | Body missing, malformed JSON, or `url` not a string. `details.fields` lists issues. | Fix the request |
| 422 | `invalid_url` | Not a valid web address, unsupported scheme, credentials in URL, or domain does not resolve | Fix the URL |
| 400 | `blocked_url` | Private, internal, loopback or metadata address, or a non-standard port | Use a public website |
| 415 | `unsupported_content` | Link is not an HTML page (`details.content_type`) | Link to a web page |
| 422 | `insufficient_content` | Almost no readable text | Try a more specific page |
| 502 | `site_unreachable` | DNS/connection failure, 404/5xx, broken or excessive redirects | Retry later |
| 502 | `site_access_denied` | 401/403/429 or bot protection (`details.status`) | Try another page or site |
| 504 | `site_timeout` | Website too slow | Retry later |
| 429 | `rate_limited` | Too many requests. A `Retry-After` header gives seconds to wait. | Back off |
| 502 | `llm_invalid_output` | AI output failed validation after retry and fallback | Retry |
| 503 | `llm_unavailable` | AI provider busy or unavailable | Retry after ~1 min |
| 503 | `llm_not_configured` | Server has no AI key configured | Server admin |
| 500 | `internal_error` | Unexpected error (logged with `request_id`) | Report the `request_id` |

### Timing

Typical response time is 13–30 seconds for a fresh analysis, and under 100 ms for a cached one. Set client timeouts to at least **120 seconds**.
